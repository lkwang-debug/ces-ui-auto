## 2026-07-29 真实页面复核

- 25 个子菜单均使用目标路由、页面标题和专属正文/控件进行可达性断言，不再接受 URL 已变化但正文仍停留在上一页的情况。
- 用户管理和终端管理已覆盖真实导入弹窗、覆盖选项、模板下载、基于模板生成运行时文件及真实导出文件校验。覆盖/不覆盖的数据提交场景仍需使用可清理的专用组织数据完成验收。
- 会议场景管理的当前产品形态不是 CRUD，而是 `会控/培训/讨论` 三种内置模板和默认场景保存；用例按此真实能力断言。
- 服务器列表是服务器分类和状态卡片，不是表格；用例校验分类、服务器类型和状态展示。
- 会议日志导出、服务器日志下载均执行真实下载并校验非空文件。
- 录制任务通过 `UIAUTO_RECORD_TASK_KEYWORD` 定位固定任务；终端日志通过专用账号、设备 ID、日志类型和 `UIAUTO_TERMINAL_LOG_TRIGGER_COMMAND` 造数。开发模式缺失时跳过，`UIAUTO_ACCEPTANCE_MODE=1` 时作为前置失败。
- 仅备份恢复、服务器启停/删除、结束在线会议属于 `destructive`。备份文件上传/删除、用户和终端批量删除、录制任务停止/删除、开发者凭据重置/删除必须限定为本用例创建的数据，属于普通回归。

- 默认：`python run.py`，自动排除 `destructive`。
- 高风险：`python run.py --include-destructive`，仅允许在可重置的专用环境运行。
- 所有创建型用例使用唯一名称并在 fixture teardown 清理。
- 环境数据不足使用 `pytest.skip`；功能与断言不符必须失败，不能用跳过掩盖。
- 新增模块前必须先补 Page Object、清理能力和失败截图，再登记为已覆盖。
- 登录失败与验证码测试使用 `UIAUTO_LOGIN_TEST_USERNAME/PASSWORD`；该账号必须具备后台登录权限。未配置时兼容使用管理员，但持续集成应配置专用账号。
